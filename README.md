# Tarkvaraarenduse-ja-koodihalduse-alused-LTAT.02.031-

Olen Tartu ülikooli keemia magistratuuri tudeng. Tegin seda repot LTAT.02.031 kursuse materjalide jaoks :) Ma ei ole päriselt programmeerimises uustulnuk, kuna olen Pythonis isegi mingeid andmetöötluse projekte teinud, kuigi mul on tuntuvalt väga fragmentaarsed teadmised, ehk ei tea hästi ja automaatselt palju nö baasasju, eriti see bashis ja R-s. Mul oleks tugevat soovi nii oma teadmisi värskendada kui saada baasasjades praktikat.
